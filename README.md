# 🌐 Portfólio Pessoal

Meu primeiro projeto de portfólio desenvolvido do zero utilizando **HTML e CSS**.

Este projeto foi criado como forma de praticar conceitos de estruturação semântica, estilização, layouts, responsividade e organização de código, além de experimentar diferentes ideias de design e interface.

Mais do que um portfólio, este projeto representa parte do meu processo de aprendizado e evolução como desenvolvedora.
